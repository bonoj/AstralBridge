# AstralBridge

AstralBridge is a disposable executable expedition for discovering the cheapest reliable crossing between this browser apparatus and an independently instantiated external model conversation.

The repository already runs. It inherits a working browser substrate and a model-operated build, preview, promotion, and deployment path. That ancestry is starting material, not product identity.

The current question is in `EXPEDITION.md`.

## For the model operating this expedition

Begin here, then read:

1. `EXPEDITION.md` for the current problem and finish line.
2. `SEMANTIC_SURFACE.md` for truths about machinery that exists right now.
3. `CLONE_AND_DEPLOY.md` for the deployment protocol.

Then inspect source wherever implementation detail matters. Code and executable evidence remain authority.

You are the technical operator. Do not make the human inspect SHAs, shuttle files, edit workflow configuration, diagnose Actions, or perform routine deployment. Use the repository machinery yourself wherever your tools permit it. Ask for human intervention only when an external account or product boundary genuinely requires it, and ask for the smallest possible action.

Do not preserve inherited machinery merely because it exists. Delete, replace, or ignore it when the expedition does not need it. Likewise, do not generalize a working seam merely because a reusable abstraction is imaginable.

Prefer executable evidence over speculative architecture.

Build. Run. Inspect. Diagnose. Simplify. Publish a candidate. Let the human experience it. Continue until the finish line in `EXPEDITION.md` is actually met.

## Repository roles

`EXPEDITION.md` defines the present investigation.

`SEMANTIC_SURFACE.md` records relevant truths about the current code. It is descriptive, not prescriptive.

`CLONE_AND_DEPLOY.md` defines model-operated candidate, preview, promotion, and Pages deployment.

`src/` contains authored browser source.

`tools/build.mjs` produces the self-contained executable.

Root `index.html` is a promoted release artifact, not authored source.

## Authority
